- **Breaking:** verify TLS certificates of RPC endpoints by default (previously `InsecureSkipVerify` was always enabled). Set `insecure_skip_verify = true` in the network TOML config, use `ClientBuilder.WithInsecureSkipVerify(true)` or set `SETH_INSECURE_SKIP_VERIFY=true` (all networks) to restore the old behaviour in testing environments with self-signed certificates.
- Add `WithInsecureSkipVerify` to `ClientBuilder` for programmatic usage
- RPC HTTP transport now honours `HTTP_PROXY`/`HTTPS_PROXY`/`NO_PROXY` environment variables.
